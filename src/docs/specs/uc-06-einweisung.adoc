==== Persona Use Case

[cols="1,3"]
|===
|Feld |Inhalt

|Use-Case-ID
|UC-06

|Name
|Einweisung anlegen

|Primary Actor
|Rolf (Wart)

|Stakeholders
a|
* *Mitglied* — möchte einweisungspflichtige Geräte ausleihen können.
* *Verein* — braucht eine nachvollziehbare Dokumentation für die Haftungssicherung.

|Trigger
|Rolf hat eine Einweisung physisch durchgeführt und will sie im System dokumentieren.

|Vorbedingungen
a|
* Das Mitglied mit der angegebenen Mitglieds-ID existiert im System.
* Die Kategorie mit der angegebenen Kategorie-ID existiert im System.

|Main Success Scenario
a|
. Rolf ruft `leihgut einweise <mitglied-id> <kategorie-id>` auf.
. Das System prüft, ob das Mitglied existiert — Ergebnis: ja.
. Das System prüft, ob die Kategorie existiert — Ergebnis: ja.
. Das System prüft, ob `Kategorie.einweisungspflichtig` gesetzt ist — Ergebnis: true.
. Das System prüft, ob eine Einweisung für dieses Mitglied und diese Kategorie bereits vorhanden ist — Ergebnis: nein.
. Das System legt die Einweisung an: `(mitgliedId, kategorieId, dokumentiertAm = heute)`.
. Das System gibt eine Bestätigung auf stdout aus: Mitglieds-ID, Name, Kategorie-ID, Bezeichnung, Datum.

|Extensions
a|
*2a. Mitglied nicht gefunden:* +
Das System gibt „Mitglied nicht gefunden" auf stderr aus und bricht mit Exit-Code ≠ 0 ab.

*3a. Kategorie nicht gefunden:* +
Das System gibt „Kategorie nicht gefunden" auf stderr aus und bricht mit Exit-Code ≠ 0 ab.

*4a. Kategorie nicht einweisungspflichtig:* +
Das System gibt einen Hinweis auf stderr aus: „Hinweis: Kategorie ist nicht einweisungspflichtig. Einweisung wird trotzdem erfasst." +
Der Use Case läuft ab Schritt 5 weiter. Die Einweisung wird angelegt.

*5a. Einweisung bereits vorhanden:* +
Das System verhält sich idempotent: Es legt keine neue Einweisung an und gibt stattdessen auf stdout aus: „Einweisung bereits vorhanden (erfasst: <datum>). Keine Änderung." +
Exit-Code: 0.

|Nachbedingungen
|Die Einweisung `(mitgliedId, kategorieId)` existiert im System. +
Das Mitglied darf nun Gegenstände der betreffenden Kategorie ausleihen, sofern alle weiteren Ausgabebedingungen erfüllt sind (BR-010).

|Geschäftsregeln
|BR-002, BR-010, BR-037, BR-038, BR-039, BR-042
|===

==== System Use Case: CLI `leihgut einweise`

===== Kommando

[source]
----
leihgut einweise <mitglied-id> <kategorie-id> [--notiz <text>]
----

[cols="1,2,3"]
|===
|Parameter |Pflicht |Beschreibung

|`<mitglied-id>`
|ja
|ID des Mitglieds, das eingewiesen wurde.

|`<kategorie-id>`
|ja
|ID der Kategorie, für die die Einweisung gilt.

|`--notiz <text>`
|nein
|Freitextnotiz, z. B. Datum der Einweisung oder Name des Geräts. Wird gespeichert, aber nicht ausgewertet.
|===

===== Validierungen

[cols="1,1,3,3"]
|===
|Schritt |Bedingung |Verhalten |BR

|V-1
|Mitglied mit `<mitglied-id>` nicht gefunden
|Ausgabe auf stderr: `Mitglied nicht gefunden.` +
Exit-Code: 1
|BR-037

|V-2
|Kategorie mit `<kategorie-id>` nicht gefunden
|Ausgabe auf stderr: `Kategorie nicht gefunden.` +
Exit-Code: 1
|BR-037

|V-3
|`Kategorie.einweisungspflichtig = false`

|BR-002, BR-037

|V-4
|Einweisung für `mitgliedId + kategorieId` bereits vorhanden

`Einweisung bereits vorhanden (erfasst: <datum>). Keine Änderung.` +
Exit-Code: 0
|BR-037
|===

===== Verarbeitung

. Wenn noch keine Einweisung für `(mitgliedId, kategorieId)` existiert: +
  Einweisung anlegen mit `mitgliedId`, `kategorieId`, `dokumentiertAm = heute`.
. Andernfalls: keine Änderung (idempotent).

==== Anforderungen (EARS-Syntax)

[cols="1,1,5"]
|===
|ID |EARS-Typ |Anforderung

|EARS-06-01
|When
|*When* der Wart den Befehl `leihgut einweise <mitglied-id> <kategorie-id>` ausführt und Mitglied und Kategorie existieren und für dieses Paar noch keine Einweisung vorhanden ist, *shall* das System eine Einweisung mit Mitglieds-ID, Kategorie-ID und aktuellem Datum anlegen und eine Bestätigung auf stdout ausgeben. _(BR-037)_

|EARS-06-02
|When
|*When* der Wart den Befehl `leihgut einweise` mit einer Mitglieds-ID aufruft, die im System nicht existiert, *shall* das System die Verarbeitung mit einer Fehlermeldung auf stderr und Exit-Code ≠ 0 abbrechen, ohne eine Einweisung anzulegen. _(BR-037)_

|EARS-06-03
|When
|*When* der Wart den Befehl `leihgut einweise` für eine Kategorie aufruft, bei der `einweisungspflichtig = false` ist, *shall* das System einen Hinweis auf stderr ausgeben und die Einweisung dennoch anlegen. _(BR-002, BR-037)_

|EARS-06-04
|When
|*When* der Wart den Befehl `leihgut einweise` für eine Mitglied-Kategorie-Kombination aufruft, für die bereits eine Einweisung gespeichert ist, *shall* das System idempotent reagieren: keine neue Einweisung anlegen, Exit-Code 0 zurückgeben und auf stdout melden, dass die Einweisung bereits vorhanden ist. _(BR-037)_

|EARS-06-05
|While
|*While* für ein Mitglied keine Einweisung für eine einweisungspflichtige Kategorie gespeichert ist, *shall* das System jede Ausgabe eines Gegenstands dieser Kategorie an dieses Mitglied ablehnen. _(BR-010, BR-037)_
|===
