== Fehlerschema

=== Einheitliches JSON-Fehlerformat

Alle REST-Fehlermeldungen folgen diesem Schema:

[source,json]
----
{
  "fehlercode": "GEGENSTAND_NICHT_VERFUEGBAR",
  "nachricht": "Gegenstand INV-007 ist derzeit ausgeliehen.",
  "details": {}
}
----

[cols="1,3"]
|===
|Feld |Beschreibung

|`fehlercode`
|Maschinenlesbarer Bezeichner in SCREAMING_SNAKE_CASE. Stabil zwischen Versionen.

|`nachricht`
|Deutschsprachige Klartextmeldung für den Client.

|`details`
|Optionales Objekt mit kontextspezifischen Zusatzinformationen (z.B. `{ "status": "IN_PRUEFUNG" }`). Kann leer sein.
|===

=== CLI-Fehlerschema

CLI-Kommandos schreiben Fehlermeldungen auf `stderr` und beenden mit Exit-Code `1`.
Erfolgreiche Ausgaben gehen auf `stdout`, Exit-Code `0`.

Format der stderr-Meldung:
----
FEHLER [FEHLERCODE]: Deutschsprachige Erklärung.
----

Beispiel:
----
FEHLER [ABZUG_UEBERSTEIGT_KAUTION]: Abzug (45 EUR) übersteigt hinterlegte Kaution (25 EUR).
----
