== Beschreibung

Als Wart möchte ich abgeschlossene Prüfprotokolle einsehen können, damit ich die vollständige Prüfhistorie eines Gegenstands nachvollziehen und bei Bedarf frühere Prüfergebnisse mit Abzügen und Notizen nachlesen kann.

Zu implementieren sind die Endpunkte `GET /pruefungen` und `GET /pruefungen/:id` im `PruefungController`. Der Controller delegiert an den `PruefungService`, der die Abfragen über das Prüfprotokoll-Repository ausführt.

Unterstützter Query-Parameter für `GET /pruefungen`:

- `?gegenstandId=<id>` — liefert nur Prüfprotokolle des angegebenen Gegenstands

Jedes Prüfprotokoll enthält mindestens: Prüfergebnis, Kautionsabzug (Betrag), Notiz des Warts sowie Datum der Prüfung.

Zugriff ist auf die Rollen `wart` und `thekendienst` beschränkt. Mitglieder erhalten 403.

== Akzeptanzkriterien

[source,gherkin]
----
Feature: Prüfprotokolle abfragen

  Scenario: Alle Prüfprotokolle abrufen
    Given der Benutzer ist als Wart authentifiziert
    And es existieren Prüfprotokolle in der Datenbank
    When er GET /pruefungen aufruft
    Then erhält er den Status 200
    And die Antwort enthält eine Liste aller Prüfprotokolle

  Scenario: Keine Prüfprotokolle vorhanden
    Given der Benutzer ist als Wart authentifiziert
    And es existieren keine Prüfprotokolle in der Datenbank
    When er GET /pruefungen aufruft
    Then erhält er den Status 200
    And die Antwort enthält eine leere Liste

  Scenario: Prüfprotokolle nach Gegenstand filtern
    Given der Benutzer ist als Wart authentifiziert
    And Gegenstand mit ID "G-7" hat drei Prüfprotokolle
    When er GET /pruefungen?gegenstandId=G-7 aufruft
    Then erhält er den Status 200
    And die Antwort enthält genau die drei Prüfprotokolle für Gegenstand G-7

  Scenario: Einzelnes Prüfprotokoll anhand bekannter ID abrufen
    Given der Benutzer ist als Wart authentifiziert
    And ein Prüfprotokoll mit ID "P-12" existiert
    When er GET /pruefungen/P-12 aufruft
    Then erhält er den Status 200
    And die Antwort enthält das vollständige Prüfprotokoll mit Ergebnis, Abzug, Notiz und Datum

  Scenario: Prüfprotokoll mit unbekannter ID
    Given der Benutzer ist als Wart authentifiziert
    And kein Prüfprotokoll mit ID "P-999" existiert
    When er GET /pruefungen/P-999 aufruft
    Then erhält er den Status 404

  Scenario: Mitglied hat keinen Zugriff
    Given der Benutzer ist als Mitglied authentifiziert
    When er GET /pruefungen aufruft
    Then erhält er den Status 403
----
