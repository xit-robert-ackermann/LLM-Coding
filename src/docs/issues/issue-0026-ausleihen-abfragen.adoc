== Beschreibung

Als Thekendienst möchte ich alle laufenden und abgeschlossenen Ausleihen einsehen können, damit ich jederzeit einen vollständigen Überblick über ausgeliehene Gegenstände habe und gezielt nach Mitglied oder Status filtern kann.

Zu implementieren sind die Endpunkte `GET /ausleihen` und `GET /ausleihen/:id` im `AusleiheController`. Der Controller delegiert an den `AusleiheService`, der die Abfragen über das Ausleihe-Repository ausführt.

Unterstützte Query-Parameter für `GET /ausleihen`:

- `?mitgliedId=<id>` — liefert nur Ausleihen des angegebenen Mitglieds
- `?status=OFFEN|ABGESCHLOSSEN` — filtert nach Ausleihestatus

Zugriff ist auf die Rollen `thekendienst` und `wart` beschränkt. Mitglieder erhalten 403.

== Akzeptanzkriterien

[source,gherkin]
----
Feature: Ausleihen abfragen

  Scenario: Alle Ausleihen abrufen
    Given der Benutzer ist als Thekendienst authentifiziert
    And es existieren Ausleihen in der Datenbank
    When er GET /ausleihen aufruft
    Then erhält er den Status 200
    And die Antwort enthält eine Liste aller Ausleihe-Objekte

  Scenario: Keine Ausleihen vorhanden
    Given der Benutzer ist als Thekendienst authentifiziert
    And es existieren keine Ausleihen in der Datenbank
    When er GET /ausleihen aufruft
    Then erhält er den Status 200
    And die Antwort enthält eine leere Liste

  Scenario: Ausleihen nach Status filtern
    Given der Benutzer ist als Thekendienst authentifiziert
    And es existieren offene und abgeschlossene Ausleihen
    When er GET /ausleihen?status=OFFEN aufruft
    Then erhält er den Status 200
    And die Antwort enthält ausschließlich Ausleihen mit Status OFFEN

  Scenario: Ausleihen eines bestimmten Mitglieds abrufen
    Given der Benutzer ist als Thekendienst authentifiziert
    And Mitglied mit ID "M-42" hat zwei laufende Ausleihen
    When er GET /ausleihen?mitgliedId=M-42 aufruft
    Then erhält er den Status 200
    And die Antwort enthält genau die zwei Ausleihen von Mitglied M-42

  Scenario: Einzelne Ausleihe anhand bekannter ID abrufen
    Given der Benutzer ist als Thekendienst authentifiziert
    And eine Ausleihe mit ID "A-99" existiert
    When er GET /ausleihen/A-99 aufruft
    Then erhält er den Status 200
    And die Antwort enthält das vollständige Ausleihe-Objekt mit ID "A-99"

  Scenario: Einzelne Ausleihe mit unbekannter ID
    Given der Benutzer ist als Thekendienst authentifiziert
    And keine Ausleihe mit ID "A-999" existiert
    When er GET /ausleihen/A-999 aufruft
    Then erhält er den Status 404

  Scenario: Mitglied hat keinen Zugriff
    Given der Benutzer ist als Mitglied authentifiziert
    When er GET /ausleihen aufruft
    Then erhält er den Status 403
----
