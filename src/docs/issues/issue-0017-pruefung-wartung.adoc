== Beschreibung

Dieser EPIC bündelt die CLI-Kommandos, die der Wart nach der Rückgabe eines Gegenstands ausführt.
Er schließt den Ausleihekreislauf ab: Prüfprotokoll erfassen (inkl. Kautionsverrechnung), Wartungsabschluss nach erledigter Instandhaltung sowie Einweisungen für Mitglieder anlegen.

Alle drei Use Cases werden ausschließlich über die CLI bedient.
Der CLI-Prozess teilt den NestJS-DI-Container mit der REST-API, sodass dieselben Services und Repositories genutzt werden.

CLI-Befehle:

* `leihgut pruefe <ausleiheId> --ergebnis <OK|SCHADEN|VERLOREN|IRREPARABEL> [--abzug <euro>] [--notiz <text>]`
* `leihgut warte <gegenstandId>`
* `leihgut einweise <mitgliedId> <kategorieId>`

Enthaltene Stories:

* 0018 — Prüfprotokoll erfassen (UC-04)
* 0019 — Wartungsabschluss (UC-05)
* 0020 — Einweisung anlegen (UC-06)

== Akzeptanzkriterien

[source,gherkin]
----
Feature: Prüfung, Wartung und Einweisung

  Scenario: Wart führt vollständigen Prüfzyklus durch
    Given ein zurückgegebener Gegenstand mit Status IN_PRUEFUNG
    When der Wart das Prüfergebnis über die CLI eingibt
    Then wird die Ausleihe abgeschlossen und die Kaution korrekt verrechnet
    And der Gegenstand erhält den korrekten Folgestatus

  Scenario: Wart schließt Wartung ab
    Given ein Gegenstand mit Status WARTUNGSFAELLIG
    When der Wart die Wartung über die CLI abschließt
    Then wechselt der Gegenstandsstatus auf VERFUEGBAR
    And der Nutzungszähler wird auf 0 zurückgesetzt

  Scenario: Wart legt Einweisung an
    Given ein gültiges Mitglied und eine gültige Kategorie
    When der Wart die Einweisung über die CLI anlegt
    Then ist die Einweisung dauerhaft gespeichert
    And das Mitglied kann einweisungspflichtige Gegenstände dieser Kategorie ausleihen
----
