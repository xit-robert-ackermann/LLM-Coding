== Beschreibung

Als Thekendienst möchte ich eine laufende Ausleihe verlängern,
damit ein Mitglied mehr Zeit für die Rückgabe erhält, ohne einen Neuvertrag aufzusetzen.

*Technischer Kontext:*
Der Endpunkt `PATCH /ausleihen/:id/verlaengern` wird durch `AusleiheController.verlaengern()`
bedient; die Logik liegt in `AusleiheService.verlaengern()`.

Die Methode prüft in dieser Reihenfolge:

. Die Ausleihe mit der angegebenen ID existiert — andernfalls 404 `AUSLEIHE_NICHT_GEFUNDEN`.
. Die Ausleihe hat den Status `OFFEN` und ist noch nicht verlängert worden (`verlängert = false`) (BR-012).
. Die Rückgabefrist liegt nicht in der Vergangenheit, d. h. die Ausleihe ist nicht überfällig (BR-013).
. Es existiert keine offene Vormerkung für die Gegenstandskategorie (BR-013).

Bei erfolgreicher Prüfung:

* Das Flag `verlängert` wird auf `true` gesetzt.
* Die neue Rückgabefrist = bisherige Rückgabefrist + Leihdauer der Kategorie (BR-012).
* Die aktualisierte Ausleihe wird mit Status 200 zurückgegeben.

Eine Verlängerung ist genau einmal je Ausleihe möglich (BR-012).
Ist die Ausleihe bereits verlängert, überfällig oder durch eine Vormerkung blockiert,
wird in allen Fällen 409 `VERLAENGERUNG_NICHT_MOEGLICH` geworfen (BR-013).

== Akzeptanzkriterien

[source,gherkin]
----
Feature: Ausleihe verlängern

  Scenario: Erfolgreiche Verlängerung
    Given eine offene, nicht verlängerte und nicht überfällige Ausleihe
    And keine Vormerkung auf die Gegenstandskategorie
    When der Thekendienst PATCH /ausleihen/:id/verlaengern aufruft
    Then antwortet der Server mit 200
    And die neue Rückgabefrist entspricht der alten Rückgabefrist plus Leihdauer
    And das Flag "verlängert" ist true

  Scenario: Ausleihe bereits verlängert
    Given eine offene Ausleihe mit verlängert = true
    When der Thekendienst PATCH /ausleihen/:id/verlaengern aufruft
    Then antwortet der Server mit 409
    And der Fehlercode ist VERLAENGERUNG_NICHT_MOEGLICH

  Scenario: Ausleihe überfällig
    Given eine offene Ausleihe, deren Rückgabefrist vor dem heutigen Tag liegt
    When der Thekendienst PATCH /ausleihen/:id/verlaengern aufruft
    Then antwortet der Server mit 409
    And der Fehlercode ist VERLAENGERUNG_NICHT_MOEGLICH

  Scenario: Offene Vormerkung für die Kategorie
    Given eine offene, nicht verlängerte Ausleihe
    And eine offene Vormerkung eines anderen Mitglieds auf dieselbe Gegenstandskategorie
    When der Thekendienst PATCH /ausleihen/:id/verlaengern aufruft
    Then antwortet der Server mit 409
    And der Fehlercode ist VERLAENGERUNG_NICHT_MOEGLICH

  Scenario: Unbekannte Ausleihe-ID
    Given eine ID, zu der keine Ausleihe existiert
    When der Thekendienst PATCH /ausleihen/:id/verlaengern aufruft
    Then antwortet der Server mit 404
    And der Fehlercode ist AUSLEIHE_NICHT_GEFUNDEN
----
