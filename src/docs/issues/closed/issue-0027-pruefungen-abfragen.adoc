== Beschreibung

Als Wart möchte ich sehen, welche Ausleihen gerade in Prüfung sind (Status IN_PRUEFUNG),
damit ich weiß, welche Gegenstände ich als nächstes prüfen soll.

Zu implementieren ist der Endpunkt `GET /pruefungen` im `PruefungController`.
Der Controller delegiert an den `PruefungService`, der alle Ausleihen zurückgibt,
bei denen der zugehörige Gegenstand den Status `IN_PRUEFUNG` hat.

Dies entspricht semantisch einem Filter auf `GET /ausleihen?status=IN_PRUEFUNG`,
ist aber als eigener, sprechend benannter Endpunkt für den Wart-Workflow vorgesehen.

Zugriff ist auf die Rollen `wart` und `thekendienst` beschränkt. Mitglieder erhalten 403.

== Akzeptanzkriterien

[source,gherkin]
----
Feature: Prüf-Arbeitsliste abrufen

  Scenario: Ausleihen mit Status IN_PRUEFUNG abrufen
    Given der Benutzer ist als Wart authentifiziert
    And 2 Ausleihen existieren, deren Gegenstand den Status IN_PRUEFUNG hat
    When er GET /pruefungen aufruft
    Then erhält er den Status 200
    And die Antwort enthält genau diese 2 Ausleihen

  Scenario: Kein Gegenstand in Prüfung
    Given der Benutzer ist als Wart authentifiziert
    And kein Gegenstand hat den Status IN_PRUEFUNG
    When er GET /pruefungen aufruft
    Then erhält er den Status 200
    And die Antwort enthält eine leere Liste

  Scenario: Mitglied hat keinen Zugriff
    Given der Benutzer ist als Mitglied authentifiziert
    When er GET /pruefungen aufruft
    Then erhält er den Status 403
----
